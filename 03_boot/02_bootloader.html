① GRUB Legacy と GRUB2 の比較

重要ポイント①：GRUB Legacy（0.9x系）と GRUB2（1.9x/2.x系）は設定ファイルの場所・書式が大きく異なる
現代のディストリビューションはほぼすべて GRUB2 を採用していますが、 LPIC-201 では両方の知識が求められます。

⚠️ GRUB Legacy（0.9x系）

  • 設定ファイル：/boot/grub/menu.lst
    または /boot/grub/grub.conf
  • ディスク表記：(hd0,0)（0始まり）
  • 設定を手動で直接編集
  • ステージ構成：Stage1・Stage1.5・Stage2
  • 現在はほぼ使用されない（レガシー）
  • インストール：grub-install

✅ GRUB2（1.9x / 2.x系）

  • 設定ファイル：/boot/grub/grub.cfg
  • ディスク表記：(hd0,1)（パーティションは1始まり）
  • 設定は /etc/default/grub を編集後 update-grub で自動生成
  • モジュール方式で機能を動的に追加
  • UEFI・GPT・暗号化ディスクに対応
  • インストール：grub-install / grub2-install

② GRUB Legacy の設定

/boot/grub/menu.lst（または grub.conf）の構造

# /boot/grub/menu.lst（GRUB Legacy の設定ファイル）

# グローバル設定
default=0          # デフォルトで起動するエントリ番号（0始まり）
timeout=5          # 起動メニューの表示秒数
splashimage=(hd0,0)/boot/grub/splash.xpm.gz

# 起動エントリ 1（デフォルト）
title           Ubuntu, kernel 2.6.32-21-generic
root            (hd0,0)       # ← 1番目のディスク・1番目のパーティション（0始まり）
kernel          /boot/vmlinuz-2.6.32-21-generic root=/dev/sda1 ro quiet splash
initrd          /boot/initrd.img-2.6.32-21-generic

# 起動エントリ 2（旧カーネル）
title           Ubuntu, kernel 2.6.32-20-generic (recovery mode)
root            (hd0,0)
kernel          /boot/vmlinuz-2.6.32-20-generic root=/dev/sda1 ro single
initrd          /boot/initrd.img-2.6.32-20-generic

GRUB Legacy のディスク表記

GRUB 表記意味Linux デバイス名
(hd0)1番目のハードディスク全体/dev/sda
(hd0,0)1番目のディスクの1番目のパーティション/dev/sda1
(hd0,1)1番目のディスクの2番目のパーティション/dev/sda2
(hd1,0)2番目のディスクの1番目のパーティション/dev/sdb1
(hd1,4)2番目のディスクの1番目の論理パーティション/dev/sdb5
⚠️ GRUB Legacy と GRUB2 のパーティション番号の違い
・GRUB Legacy：(hd0,0) = 1番目のディスクの1番目のパーティション（0始まり）
・GRUB2：(hd0,1) = 1番目のディスクの1番目のパーティション（1始まり）
同じパーティションでも番号が異なるため注意が必要です。

③ GRUB2 の設定

重要ポイント②：GRUB2 の設定は /etc/default/grub を編集し、update-grub で /boot/grub/grub.cfg を自動生成する
grub.cfg は自動生成ファイルのため直接編集してはいけません。

/etc/default/grub の設定

# /etc/default/grub（GRUB2 のユーザー設定ファイル）

# デフォルトで起動するエントリ（0始まり、または "saved"）
GRUB_DEFAULT=0

# 前回起動したエントリを記憶して次回もそれを使用
# GRUB_DEFAULT=saved
# GRUB_SAVEDEFAULT=true

# 起動メニューの表示秒数（0=即時起動、-1=無制限）
GRUB_TIMEOUT=5

# 通常起動時のカーネルパラメータ
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"

# すべてのエントリに追加するカーネルパラメータ
GRUB_CMDLINE_LINUX=""

# ターミナルの設定
GRUB_TERMINAL=console

# 解像度の設定
# GRUB_GFXMODE=1024x768

# ディストリビューション名
GRUB_DISTRIBUTOR=`lsb_release -i -s 2> /dev/null || echo Debian`

設定変更の反映手順

# 1. /etc/default/grub を編集
$ sudo vi /etc/default/grub

# 2. grub.cfg を再生成して反映
# Debian / Ubuntu 系
$ sudo update-grub
Sourcing file `/etc/default/grub'
Generating grub configuration file ...
Found linux image: /boot/vmlinuz-6.8.0-51-generic
Found initrd image: /boot/initrd.img-6.8.0-51-generic
done

# RHEL / CentOS 系（BIOS）
$ sudo grub2-mkconfig -o /boot/grub2/grub.cfg

# RHEL / CentOS 系（UEFI）
$ sudo grub2-mkconfig -o /boot/efi/EFI/redhat/grub.cfg

# 生成された grub.cfg の確認
$ cat /boot/grub/grub.cfg | head -40

/boot/grub/grub.cfg の構造（自動生成）

# /boot/grub/grub.cfg（自動生成ファイル・直接編集不可）
# DO NOT EDIT THIS FILE
# It is automatically generated by grub-mkconfig using templates
# from /etc/grub.d and settings from /etc/default/grub

# グローバル設定
set default="0"
set timeout=5
set timeout_style=menu

# 起動エントリ
menuentry 'Ubuntu, with Linux 6.8.0-51-generic' {
    recordfail
    load_video
    gfxmode $linux_gfx_mode
    insmod gzio
    insmod part_gpt
    insmod ext2
    set root='(hd0,gpt2)'   # ← 1始まり（GRUB2）
    linux   /boot/vmlinuz-6.8.0-51-generic root=UUID=xxxx-xxxx ro quiet splash
    initrd  /boot/initrd.img-6.8.0-51-generic
}

menuentry 'Ubuntu, with Linux 6.8.0-51-generic (recovery mode)' {
    set root='(hd0,gpt2)'
    linux   /boot/vmlinuz-6.8.0-51-generic root=UUID=xxxx-xxxx ro recovery nomodeset
    initrd  /boot/initrd.img-6.8.0-51-generic
}

/etc/grub.d/ のスクリプト構成

$ ls /etc/grub.d/
00_header        # GRUB の基本設定・ヘッダー生成
05_debian_theme  # テーマ設定
10_linux         # インストール済みLinuxカーネルのエントリを自動生成
20_linux_xen     # Xen ハイパーバイザー用エントリ
30_os-prober     # 他のOSを自動検出（Windows など）
40_custom        # カスタムエントリを追加する場所
41_custom        # 追加のカスタムエントリ

# カスタムエントリを追加する場合は 40_custom を編集
$ sudo vi /etc/grub.d/40_custom
# 以下を追記
menuentry "My Custom Entry" {
    set root='(hd0,1)'
    linux /boot/vmlinuz root=/dev/sda1 ro
    initrd /boot/initrd.img
}

GRUB2 のインストール

# MBR に GRUB2 をインストール（BIOS システム）
$ sudo grub-install /dev/sda
Installing for i386-pc platform.
Installation finished. No error reported.

# 特定ディレクトリを指定してインストール
$ sudo grub-install --boot-directory=/boot /dev/sda

# UEFI システムへのインストール
$ sudo grub-install --target=x86_64-efi --efi-directory=/boot/efi

# インストール後に grub.cfg を生成
$ sudo update-grub

# GRUB のバージョン確認
$ grub-install --version
grub-install (GRUB) 2.12

④ 起動オプションの設定

重要ポイント③：起動オプションは /etc/default/grub の GRUB_CMDLINE_LINUX_DEFAULT に設定するか、GRUB メニューで一時的に変更できる
一時的な変更は GRUB メニューで e キーを押して編集します。

主要な起動オプション（GRUB_CMDLINE_LINUX_DEFAULT）

起動オプションを選択して設定例を確認しましょう

GRUB_CMDLINE_LINUX と GRUB_CMDLINE_LINUX_DEFAULT の違い

変数名適用範囲用途
GRUB_CMDLINE_LINUX すべての起動エントリ
（通常・回復モード両方）		 常に必要なパラメータ
例：net.ifnames=0
GRUB_CMDLINE_LINUX_DEFAULT 通常起動エントリのみ
（回復モードには適用されない）		 通常起動時のみ必要なパラメータ
例：quiet splash

⑤ システムの回復

重要ポイント④：システムが起動しない場合は GRUB メニューの編集・レスキューモード・Live CD・chroot を使って回復する
状況に応じた適切な回復手段を選択することが重要です。

🔧
