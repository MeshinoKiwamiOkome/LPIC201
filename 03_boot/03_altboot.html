① SYSLINUX ファミリーの概要

重要ポイント①：SYSLINUX は軽量なブートローダのファミリーで、使用するメディアに応じて SYSLINUX・ISOLINUX・PXELINUX・EXTLINUX の4種類がある
すべて共通の設定ファイル書式（syslinux.cfg）を使用しますが、 用途とインストール先が異なります。

SYSLINUX ファミリー（クリックで詳細）

SYSLINUX
FAT ファイルシステム
USBメモリ・フロッピーなどの FAT パーティションから起動
ISOLINUX
ISO 9660（CD/DVD）
CD/DVD/ISO イメージから起動。Live CD に広く使用
PXELINUX
ネットワーク（PXE）
ネットワーク経由でカーネルを取得して起動（PXEブート）
EXTLINUX
ext2/3/4・Btrfs
Linux ネイティブファイルシステムのパーティションから起動

SYSLINUX ファミリー比較表

名前対応メディア主な用途設定ファイル
SYSLINUX FAT（USB・フロッピー） USB 起動メディア syslinux.cfg
ISOLINUX ISO 9660（CD/DVD） Live CD・インストール CD isolinux.cfg
PXELINUX ネットワーク（PXE/TFTP） ネットワークブート pxelinux.cfg/default
EXTLINUX ext2/3/4・Btrfs・XFS Linux パーティション起動 extlinux.conf

② SYSLINUX の設定ファイル

重要ポイント②：SYSLINUX ファミリーはすべて共通の設定ファイル書式を使用する
GRUB の設定ファイルより単純で読みやすい書式です。

syslinux.cfg / isolinux.cfg の基本書式

# syslinux.cfg / isolinux.cfg の基本構造

# グローバル設定
DEFAULT  linux              # デフォルトで起動するラベル
TIMEOUT  50                 # タイムアウト（1/10秒単位、50=5秒）
PROMPT   1                  # 1=ブートプロンプトを表示
MENU TITLE Boot Menu       # メニュータイトル

# 起動エントリ 1
LABEL    linux
  MENU LABEL ^Boot Linux
  KERNEL   /vmlinuz
  APPEND   initrd=/initrd.img root=/dev/sda1 ro quiet splash

# 起動エントリ 2（回復モード）
LABEL    recovery
  MENU LABEL Recovery Mode
  KERNEL   /vmlinuz
  APPEND   initrd=/initrd.img root=/dev/sda1 ro single

# 起動エントリ 3（メモリテスト）
LABEL    memtest
  MENU LABEL Memory Test (memtest86+)
  KERNEL   /memtest86+

# ローカルディスクから起動
LABEL    local
  MENU LABEL Boot from local disk
  LOCALBOOT 0

主要ディレクティブ一覧

ディレクティブ説明例
DEFAULTデフォルトで起動するラベル名DEFAULT linux
TIMEOUT自動起動までの時間（1/10秒単位）TIMEOUT 50（5秒）
PROMPT1=ブートプロンプト表示、0=非表示PROMPT 1
LABEL起動エントリのラベル名LABEL linux
MENU LABELメニューに表示する文字列（^ でショートカット）MENU LABEL ^Boot Linux
KERNEL起動するカーネルファイルのパスKERNEL /vmlinuz
APPENDカーネルに渡すパラメータ（initrd 含む）APPEND initrd=/initrd.img root=/dev/sda1 ro
INITRDinitrd ファイルのパス（APPEND の代替）INITRD /initrd.img
LOCALBOOTローカルディスクから起動LOCALBOOT 0
MENU DEFAULTこのエントリをデフォルトに設定LABEL ブロック内に記述
MENU HIDEこのエントリをメニューから非表示LABEL ブロック内に記述

ISOLINUX の設定例（Live CD）

# /isolinux/isolinux.cfg（Live CD 用の設定例）

UI       vesamenu.c32       # グラフィカルメニューモジュール
DEFAULT  live
TIMEOUT  300                # 30秒
MENU TITLE Ubuntu Live CD

LABEL    live
  MENU LABEL ^Start Ubuntu
  KERNEL   /casper/vmlinuz
  APPEND   initrd=/casper/initrd boot=casper quiet splash ---

LABEL    install
  MENU LABEL ^Install Ubuntu
  KERNEL   /casper/vmlinuz
  APPEND   initrd=/casper/initrd boot=casper only-ubiquity quiet splash ---

LABEL    check
  MENU LABEL Check disc for defects
  KERNEL   /casper/vmlinuz
  APPEND   initrd=/casper/initrd boot=casper integrity-check quiet splash ---

EXTLINUX のインストールと設定

# extlinux のインストール
$ sudo apt install syslinux-common extlinux

# /boot パーティションに extlinux をインストール
$ sudo extlinux --install /boot
/boot is device /dev/sda1

# MBR に syslinux の MBR コードを書き込む
$ sudo dd if=/usr/lib/syslinux/mbr/mbr.bin \
         of=/dev/sda bs=440 count=1

# /boot/extlinux.conf を作成
$ sudo vi /boot/extlinux.conf

③ PXE ブートの概要

重要ポイント③：PXE（Preboot eXecution Environment）はネットワーク経由でOSを起動する仕組みで、DHCP・TFTP・ブートローダ（PXELINUX）が連携して動作する
ディスクレスクライアントや大規模環境でのOS一括インストールに使用されます。

PXE ブートに使用するポート・プロトコル

プロトコルポート役割
DHCPUDP 67（サーバー）/ 68（クライアント）IP アドレス・TFTP サーバー情報の配布
TFTPUDP 69ブートローダ・カーネル・initrd の転送
NFSTCP/UDP 2049ルートファイルシステムのマウント
HTTPTCP 80インストールイメージ・パッケージの配布
iSCSITCP 3260ブロックデバイスのネットワーク提供
✅ PXE ブートの主な用途
・ディスクレスクライアント：ハードディスクを持たない端末の起動
・OS 一括インストール：多数のサーバーへの自動インストール（Kickstart/Preseed と組み合わせ）
・ネットワークブート：メンテナンス・診断ツールのネットワーク配布
・シンクライアント：中央管理されたデスクトップ環境の提供
