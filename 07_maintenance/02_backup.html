④ ネットワーク経由でのバックアップ

## rsync によるネットワークバックアップ（最も一般的）

# ローカルからリモートへのバックアップ
$ rsync -avz /home/user/ backup-server:/backup/home/
# -a : アーカイブモード（-rlptgoD の組み合わせ）
# -v : 詳細表示
# -z : 転送時に圧縮

# SSH 経由で安全にバックアップ（-e ssh）
$ rsync -avz -e ssh /home/user/ user@backup-server:/backup/home/

# 削除されたファイルも同期（--delete）
$ rsync -avz --delete /home/user/ backup-server:/backup/home/

# 特定ファイルを除外（--exclude）
$ rsync -avz --exclude="*.log" --exclude=".cache" /home/ backup-server:/backup/

# ドライラン（実際には実行しない）
$ rsync -avzn /home/user/ backup-server:/backup/home/

# リモートからローカルへのリストア
$ rsync -avz backup-server:/backup/home/ /home/user/

## tar + SSH によるバックアップ

# ローカルで tar して SSH 経由で転送
$ tar czf - /home/user/ | ssh backup-server "cat > /backup/home.tar.gz"

# SSH 経由でリモートから取得
$ ssh backup-server "tar czf - /home/user/" | tar xzf - -C /restore/

## dump + rmt によるリモートテープバックアップ

# リモートの磁気テープにバックアップ（rmt プロトコル）
$ sudo dump -0uf backup-server:/dev/st0 /home

## cron による定期バックアップの設定
$ crontab -e
# 毎日深夜2時に rsync でバックアップ
0 2 * * * rsync -avz --delete /home/ backup-server:/backup/home/ >> /var/log/backup.log 2>&1
# 毎週日曜日に完全バックアップ
0 1 * * 0 tar czf /backup/full-$(date +%Y%m%d).tar.gz /home/ >> /var/log/backup.log 2>&1

rsync の主要オプション

オプション説明
-aアーカイブモード（-rlptgoD）：再帰・シンボリックリンク・パーミッション・タイムスタンプ・所有者を保持
-v詳細表示（verbose）
-z転送時に圧縮
-nドライラン（実際には実行しない）
--delete送信元にないファイルを送信先から削除（完全同期）
--exclude=パターン指定パターンのファイルを除外
-e sshSSH 経由で転送
--progress転送の進捗を表示
-P--progress --partial の組み合わせ（中断後の再開）
--link-dest=ディレクトリハードリンクを使った増分バックアップ
✅ rsync によるハードリンク増分バックアップ
--link-dest オプションを使うと、変更のないファイルはハードリンクで参照するため、 容量を節約しながら完全バックアップのように見える増分バックアップが実現できます。
rsync -avz --link-dest=/backup/prev /home/ /backup/$(date +%Y%m%d)/
