① RAID の概要

重要ポイント①：RAID（Redundant Array of Independent Disks）は複数のディスクを組み合わせて性能向上・冗長性確保を実現する技術
ハードウェア RAID とソフトウェア RAID があります。Linux では mdadm でソフトウェア RAID を構築します。

③ RAID の構築（mdadm）

重要ポイント②：Linux のソフトウェア RAID は mdadm コマンドで管理する。RAID デバイスは /dev/md0 などの名前で作成される
/proc/mdstat で RAID の状態を確認できます。

mdadm による RAID 構築手順

# mdadm のインストール
$ sudo apt install mdadm

## RAID 0 の作成（4台でストライピング）
$ sudo mdadm --create /dev/md0 \
    --level=0 \
    --raid-devices=4 \
    /dev/sdb1 /dev/sdc1 /dev/sdd1 /dev/sde1
mdadm: Defaulting to version 1.2 metadata
mdadm: array /dev/md0 started.

## RAID 1 の作成（2台でミラーリング）
$ sudo mdadm --create /dev/md1 \
    --level=1 \
    --raid-devices=2 \
    /dev/sdb1 /dev/sdc1

## RAID 5 の作成（4台：3台データ + 1台パリティ分散）
$ sudo mdadm --create /dev/md2 \
    --level=5 \
    --raid-devices=4 \
    /dev/sdb1 /dev/sdc1 /dev/sdd1 /dev/sde1

## ホットスペア付き RAID 5 の作成
$ sudo mdadm --create /dev/md2 \
    --level=5 \
    --raid-devices=4 \
    --spare-devices=1 \
    /dev/sdb1 /dev/sdc1 /dev/sdd1 /dev/sde1 /dev/sdf1
#   ↑4台がアクティブ、sdf1 がホットスペア

# 作成後にファイルシステムを作成してマウント
$ sudo mkfs.ext4 /dev/md2
$ sudo mkdir /mnt/raid5
$ sudo mount /dev/md2 /mnt/raid5

mdadm の設定ファイルへの保存

# RAID 設定を /etc/mdadm/mdadm.conf に保存（起動時の自動認識に必要）
$ sudo mdadm --detail --scan | sudo tee -a /etc/mdadm/mdadm.conf
ARRAY /dev/md2 metadata=1.2 name=hostname:2 UUID=xxxxxxxx:xxxxxxxx:xxxxxxxx:xxxxxxxx

# initramfs を更新（起動時に RAID を認識させるため）
$ sudo update-initramfs -u

# /etc/fstab に追記して自動マウント
$ echo '/dev/md2  /mnt/raid5  ext4  defaults  0 2' | sudo tee -a /etc/fstab

RAID 状態の確認

# /proc/mdstat で RAID の状態を確認（最重要）
$ cat /proc/mdstat
Personalities : [raid1] [raid5] [raid6]

      3145728 blocks super 1.2 level 5, 512k chunk, algorithm 2 [4/4] [UUUU]

RAID の障害対応（インタラクティブ）

障害シナリオを選択して対応手順を確認しましょう

その他の mdadm 操作コマンド

# RAID アレイの停止
$ sudo umount /mnt/raid5
$ sudo mdadm --stop /dev/md2

# RAID アレイの再起動（開始）
$ sudo mdadm --assemble /dev/md2 /dev/sdb1 /dev/sdc1 /dev/sdd1 /dev/sde1
$ sudo mdadm --assemble --scan   # mdadm.conf から自動認識

# RAID アレイの削除
$ sudo mdadm --stop /dev/md2
$ sudo mdadm --remove /dev/md2
# 各ディスクのスーパーブロックを消去
$ sudo mdadm --zero-superblock /dev/sdb1 /dev/sdc1 /dev/sdd1 /dev/sde1

# ディスクを手動で故障状態にマーク
$ sudo mdadm --manage /dev/md2 --fail /dev/sdb1

# ディスクをアレイから削除
$ sudo mdadm --manage /dev/md2 --remove /dev/sdb1

# ディスクをアレイに追加（再構築開始）
$ sudo mdadm --manage /dev/md2 --add /dev/sdb1

# RAID アレイの拡張（ディスク追加）
$ sudo mdadm --grow /dev/md2 --raid-devices=5 --add /dev/sdf1

# メール通知の設定（/etc/mdadm/mdadm.conf）
MAILADDR admin@example.com
