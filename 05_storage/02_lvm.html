📦 LVM の管理

LVM（Logical Volume Manager）の3層構造（PV・VG・LV）を理解し、 作成から拡張・縮小・スナップショットまで LVM の全操作を学びます。

① LVM の仕組み

重要ポイント①：LVM は物理ディスクを抽象化して柔軟なボリューム管理を実現する。PV（物理ボリューム）→ VG（ボリュームグループ）→ LV（論理ボリューム）の3層構造
パーティションサイズを後から自由に変更できることが最大の利点です。

LVM の3層構造（クリックで詳細）

🔵 論理ボリューム（LV：Logical Volume）
/dev/vg0/lv_root（20G）
/dev/vg0/lv_home（50G）
/dev/vg0/lv_data（30G）
↕ LV は VG から任意のサイズで切り出す
🟣 ボリュームグループ（VG：Volume Group）
vg0（100G）
vg1（別グループ）
↕ VG は複数の PV を束ねたストレージプール
🟡 物理ボリューム（PV：Physical Volume）
/dev/sdb1（50G）
/dev/sdc1（50G）
↕ PV はディスクまたはパーティション
⚫ 物理ディスク（Physical Disk）
/dev/sdb（50G）
/dev/sdc（50G）

LVM の利点

利点説明
動的なサイズ変更稼働中のシステムでも LV のサイズを拡張・縮小できる
複数ディスクの統合複数の物理ディスクを1つの大きなストレージプールとして扱える
スナップショットLV のある時点の状態を保存してバックアップや回復に活用
ストライピング複数の PV にデータを分散して I/O 性能を向上
ミラーリングLVM レベルでのミラーリングによる冗長性確保
シンプロビジョニング実際の容量より大きな LV を作成（使用時に実容量を割り当て）

② LVM の作成

LVM 作成の全手順（ステップフロー）

1

💾 LVM 用パーティションの準備

fdisk でパーティションを作成し、タイプを 8e（Linux LVM）に設定する

2

🟡 物理ボリューム（PV）の初期化

pvcreate でパーティションを LVM の PV として初期化する

3

🟣 ボリュームグループ（VG）の作成

vgcreate で PV を束ねて VG（ストレージプール）を作成する

4

🔵 論理ボリューム（LV）の作成

lvcreate で VG から LV を切り出す

5

🔨 ファイルシステムの作成とマウント

mkfs で LV をフォーマットして mount でマウントする

## ステップ1：LVM 用パーティションの準備
$ sudo fdisk /dev/sdb
# → n（新規）→ p（プライマリ）→ Enter → Enter → t（タイプ変更）→ 8e（Linux LVM）→ w（書き込み）
$ sudo fdisk /dev/sdc
# 同様に /dev/sdc1 を作成

## ステップ2：物理ボリューム（PV）の初期化
$ sudo pvcreate /dev/sdb1 /dev/sdc1
  Physical volume "/dev/sdb1" successfully created.
  Physical volume "/dev/sdc1" successfully created.

## ステップ3：ボリュームグループ（VG）の作成
$ sudo vgcreate vg0 /dev/sdb1 /dev/sdc1
  Volume group "vg0" successfully created

# PE サイズを指定して VG を作成（デフォルト 4MB）
$ sudo vgcreate -s 8m vg0 /dev/sdb1 /dev/sdc1

## ステップ4：論理ボリューム（LV）の作成
# サイズを指定して作成
$ sudo lvcreate -L 20G -n lv_root vg0
  Logical volume "lv_root" created.

# VG の空き容量の割合で作成（-l = PE 数または割合）
$ sudo lvcreate -l 50%FREE -n lv_home vg0
$ sudo lvcreate -l 100%FREE -n lv_data vg0

## ステップ5：ファイルシステムの作成とマウント
$ sudo mkfs.ext4 /dev/vg0/lv_root
$ sudo mkfs.xfs  /dev/vg0/lv_home
$ sudo mkdir /mnt/root /mnt/home
$ sudo mount /dev/vg0/lv_root /mnt/root
$ sudo mount /dev/vg0/lv_home /mnt/home

# /etc/fstab に追記して永続化
$ echo '/dev/vg0/lv_root /mnt/root ext4 defaults 0 2' | sudo tee -a /etc/fstab

④ LVM の管理 ― 拡張・縮小・移動

ボリュームグループの拡張（PV の追加）

# 新しいディスクを PV として初期化
$ sudo pvcreate /dev/sdd1
  Physical volume "/dev/sdd1" successfully created.

# VG に PV を追加（VG が拡張される）
$ sudo vgextend vg0 /dev/sdd1
  Volume group "vg0" successfully extended

# 確認
$ sudo vgs
  VG  #PV #LV #SN Attr   VSize    VFree
  vg0   3   3   0 wz--n- 149.99g  77.99g
# → PV が 2→3 台、VG サイズが 99.99G→149.99G に拡張

物理ボリュームの移動（pvmove）

# /dev/sdb1 のデータを他の PV に移動（ディスク交換前の準備）
$ sudo pvmove /dev/sdb1
  /dev/sdb1: Moved: 12.34%
  /dev/sdb1: Moved: 45.67%
  /dev/sdb1: Moved: 100.00%

# 移動先を指定することもできる
$ sudo pvmove /dev/sdb1 /dev/sdd1

# バックグラウンドで実行（-b）
$ sudo pvmove -b /dev/sdb1

# 進捗確認
$ sudo pvs -o +pv_mda_free

ボリュームグループの縮小（PV の削除）

# ステップ1：対象 PV のデータを他の PV に移動
$ sudo pvmove /dev/sdb1

# ステップ2：VG から PV を削除
$ sudo vgreduce vg0 /dev/sdb1
  Removed "/dev/sdb1" from volume group "vg0"

# ステップ3：PV の LVM メタデータを消去
$ sudo pvremove /dev/sdb1
  Labels on physical volume "/dev/sdb1" successfully wiped.

論理ボリュームの拡張（最重要操作）

## ext4 LV の拡張手順

# 方法1：LV 拡張 → FS 拡張を別々に実行
# ステップ1：LV を 10GB 拡張
$ sudo lvextend -L +10G /dev/vg0/lv_root
  Size of logical volume vg0/lv_root changed from 20.00 GiB (5120 extents) to 30.00 GiB (7680 extents).
  Logical volume vg0/lv_root successfully resized.

# ステップ2：ファイルシステムを拡張（ext4 の場合）
$ sudo resize2fs /dev/vg0/lv_root
Resizing the filesystem on /dev/vg0/lv_root to 7864320 (4k) blocks.
The filesystem on /dev/vg0/lv_root is now 7864320 (4k) blocks long.

# 方法2：LV 拡張と FS 拡張を同時に実行（-r オプション）
$ sudo lvextend -L +10G -r /dev/vg0/lv_root
#                              ↑-r：FS も同時に拡張（resize2fs を自動実行）

# VG の空き容量をすべて使って拡張
$ sudo lvextend -l +100%FREE -r /dev/vg0/lv_root

## XFS LV の拡張（マウント中でも可能）
$ sudo lvextend -L +10G /dev/vg0/lv_home
$ sudo xfs_growfs /mnt/home    # XFS はマウントポイントを指定

論理ボリュームの縮小（ext4 のみ）

## LV の縮小（ext4 のみ。XFS は縮小不可）
## ⚠️  必ずアンマウントしてから実行すること！

# ステップ1：アンマウント
$ sudo umount /mnt/root

# ステップ2：ファイルシステムのチェック（必須）
$ sudo e2fsck -f /dev/vg0/lv_root

# ステップ3：ファイルシステムを縮小（目標サイズより小さく縮小）
$ sudo resize2fs /dev/vg0/lv_root 15G

# ステップ4：LV を縮小
$ sudo lvreduce -L 15G /dev/vg0/lv_root
  WARNING: Reducing active logical volume to 15.00 GiB.
  THIS MAY DESTROY YOUR DATA (filesystem etc.)
Do you really want to reduce vg0/lv_root? [y/n]: y
  Logical volume vg0/lv_root successfully resized.

# ステップ5：再マウント
$ sudo mount /dev/vg0/lv_root /mnt/root
⚠️ LV 縮小時の注意事項
・必ずアンマウント状態で実行する
・FS のサイズを先に縮小してから LV を縮小する（逆順はデータ破損の原因）
・XFS は縮小不可（ext2/3/4 のみ縮小可能）
・縮小前に必ず e2fsck -f でファイルシステムをチェックする
・重要なデータは事前にバックアップを取ること

論理ボリュームの削除

# LV を削除（アンマウント後に実行）
$ sudo umount /mnt/data
$ sudo lvremove /dev/vg0/lv_data
Do you really want to remove active logical volume vg0/lv_data? [y/n]: y
  Logical volume "lv_data" successfully removed.

# 確認なしで削除（-f オプション）
$ sudo lvremove -f /dev/vg0/lv_data

⑤ スナップショットの作成

重要ポイント②：LVM スナップショットはある時点の LV の状態を保存する。CoW（Copy-on-Write）方式で変更されたブロックのみを保存するため効率的
バックアップ前の一時的なスナップショットや、テスト環境の作成に活用できます。 
## スナップショットの作成
# -s：スナップショット -L：スナップショット用の領域サイズ
$ sudo lvcreate -s -L 5G -n lv_root_snap /dev/vg0/lv_root
  Logical volume "lv_root_snap" created.

# スナップショットの確認
$ sudo lvs
  LV           VG  Attr       LSize  Pool Origin  Data%  Meta%
  lv_root      vg0 owi-aos--- 20.00g
  lv_root_snap vg0 swi-a-s---  5.00g      lv_root  0.00
# s=スナップショット, o=オリジン（元の LV）

## スナップショットをマウントして内容を確認
$ sudo mkdir /mnt/snap
$ sudo mount -o ro /dev/vg0/lv_root_snap /mnt/snap
$ ls /mnt/snap

## スナップショットからリストア（元の LV を上書き）
$ sudo umount /mnt/root
$ sudo lvconvert --merge /dev/vg0/lv_root_snap
  Merging of volume vg0/lv_root_snap started.
  vg0/lv_root: Merged: 100.00%

## スナップショットの削除
$ sudo umount /mnt/snap
$ sudo lvremove /dev/vg0/lv_root_snap

## スナップショット使用量の監視
# Data% が 100% に近づくとスナップショットが無効になる
$ sudo lvs -o +snap_percent
✅ スナップショットの活用例
① バックアップ前のスナップショット：lvcreate -s → バックアップ実行 → lvremove
② システム更新前の保護：更新前にスナップショット作成 → 問題があれば lvconvert --merge で復元
③ テスト環境の作成：本番 LV のスナップショットをテスト環境として使用

📌 LVM 作成・管理の全手順まとめ

手順コマンド例説明
▼ 作成手順
① PV 初期化pvcreate /dev/sdb1 /dev/sdc1パーティションを PV として初期化
② VG 作成vgcreate vg0 /dev/sdb1 /dev/sdc1PV を束ねて VG を作成
③ LV 作成lvcreate -L 20G -n lv_root vg0VG から LV を切り出す
④ FS 作成mkfs.ext4 /dev/vg0/lv_rootLV をフォーマット
⑤ マウントmount /dev/vg0/lv_root /mnt/rootマウントして使用開始
▼ 拡張手順
VG 拡張pvcreate /dev/sdd1 → vgextend vg0 /dev/sdd1新 PV を追加して VG を拡張
LV 拡張（ext4）lvextend -L +10G -r /dev/vg0/lv_rootLV と FS を同時拡張
LV 拡張（XFS）lvextend -L +10G /dev/vg0/lv_home → xfs_growfs /mnt/homeLV 拡張後に XFS を拡張
▼ 縮小・削除手順
LV 縮小（ext4）umount → e2fsck -f → resize2fs → lvreduce必ずこの順序で実行
PV 削除pvmove /dev/sdb1 → vgreduce vg0 /dev/sdb1 → pvremove /dev/sdb1データ移動→VGから削除→PV消去
