① カーネルパラメータとは

重要ポイント①：カーネルパラメータとは、実行中のカーネルの動作を制御する設定値であり、/proc/sys/ 以下のファイルで管理される
再起動なしに動的に変更でき、sysctl コマンドまたは /proc/sys/ への直接書き込みで変更します。

/proc/sys/ のディレクトリ構造（クリックで詳細）

/proc/sys/
├── kernel/ ← カーネル全般の設定
│ ├── hostname ← ホスト名
│ ├── pid_max ← プロセスIDの最大値
│ └── sysrq ← Magic SysRq キーの有効/無効
├── vm/ ← 仮想メモリ・スワップの設定
│ ├── swappiness ← スワップの積極度（0〜100）
│ ├── dirty_ratio ← ダーティページの最大割合
│ └── overcommit_memory ← メモリオーバーコミット設定
├── net/ ← ネットワークスタックの設定
│ ├── ipv4/ip_forward ← IPフォワーディング（0/1）
│ ├── ipv4/tcp_fin_timeout ← TCP FINタイムアウト（秒）
│ └── core/somaxconn ← 接続キューの最大サイズ
└── fs/ ← ファイルシステムの設定
    ├── file-max ← ファイルディスクリプタの最大数
    └── inotify/max_user_watches ← inotify の最大監視数

② sysctl コマンド

重要ポイント②：sysctl はカーネルパラメータを確認・変更するコマンド。-w で一時変更、/etc/sysctl.conf で永続化する
/proc/sys/ への直接書き込みと同等ですが、 sysctl の方が安全で推奨されます。

基本的な使い方

# すべてのパラメータを一覧表示
$ sysctl -a
kernel.hostname = teru-LetsNote
kernel.pid_max = 32768
vm.swappiness = 60
net.ipv4.ip_forward = 0
...

# 特定のパラメータを確認
$ sysctl vm.swappiness
vm.swappiness = 60

$ sysctl net.ipv4.ip_forward
net.ipv4.ip_forward = 0

# /proc/sys/ への直接アクセスでも確認できる
$ cat /proc/sys/vm/swappiness
60

パラメータの変更（一時的）

# -w オプションで値を変更（再起動後は元に戻る）
$ sudo sysctl -w vm.swappiness=10
vm.swappiness = 10

$ sudo sysctl -w net.ipv4.ip_forward=1
net.ipv4.ip_forward = 1

$ sudo sysctl -w net.core.somaxconn=1024
net.core.somaxconn = 1024

# /proc/sys/ への直接書き込みでも変更できる（非推奨）
$ echo 10 | sudo tee /proc/sys/vm/swappiness
10

# 変更後の確認
$ sysctl vm.swappiness
vm.swappiness = 10

パラメータの永続化（/etc/sysctl.conf）

# /etc/sysctl.conf を編集して永続化
$ sudo vi /etc/sysctl.conf

# 以下の内容を追記
# メモリ・スワップの設定
vm.swappiness = 10
vm.dirty_ratio = 15

# ネットワークの設定
net.ipv4.ip_forward = 1
net.core.somaxconn = 1024
net.ipv4.tcp_fin_timeout = 30

# ファイルシステムの設定
fs.file-max = 100000

# /etc/sysctl.conf の設定を即時反映
$ sudo sysctl -p
vm.swappiness = 10
vm.dirty_ratio = 15
net.ipv4.ip_forward = 1
...

# 特定のファイルを指定して反映
$ sudo sysctl -p /etc/sysctl.d/99-custom.conf
✅ /etc/sysctl.d/ ディレクトリ（推奨）
現代のシステムでは /etc/sysctl.conf に直接書くより、 /etc/sysctl.d/ 以下に *.conf ファイルを作成する方法が推奨されます。
例：/etc/sysctl.d/99-network.conf・/etc/sysctl.d/99-vm.conf
sysctl -p または再起動時に自動的に読み込まれます。

sysctl コマンドのオプション一覧

オプション説明例
-a / --allすべてのパラメータを表示sysctl -a
-wパラメータの値を変更（一時的）sysctl -w vm.swappiness=10
-p [ファイル]設定ファイルを読み込んで反映sysctl -p（デフォルトは /etc/sysctl.conf）
-nパラメータ名を表示せず値のみ表示sysctl -n vm.swappiness
-e不明なパラメータのエラーを無視sysctl -e -p
-r パターンパターンに一致するパラメータを表示sysctl -r 'net.ipv4'

③ 重要なカーネルパラメータ（インタラクティブ）

カテゴリを選択してパラメータの詳細を確認しましょう

重要パラメータ：vm.swappiness インタラクティブデモ

60

IPフォワーディングの設定（ルーター設定の例）

# IPフォワーディングを有効化（一時的）
$ sudo sysctl -w net.ipv4.ip_forward=1
net.ipv4.ip_forward = 1

# 確認
$ cat /proc/sys/net/ipv4/ip_forward
1

# 永続化（/etc/sysctl.conf に追記）
$ echo "net.ipv4.ip_forward = 1" | sudo tee -a /etc/sysctl.conf
$ sudo sysctl -p

# または /etc/sysctl.d/ に専用ファイルを作成（推奨）
$ echo "net.ipv4.ip_forward = 1" | sudo tee /etc/sysctl.d/99-ip-forward.conf
$ sudo sysctl -p /etc/sysctl.d/99-ip-forward.conf

④ 初期RAMディスク（initramfs）

重要ポイント③：initramfs はカーネル起動直後に使用される一時的なルートファイルシステムで、本来のルートFSをマウントするために必要なツール・ドライバを提供する
LVM・RAID・暗号化ディスクなど、カーネル単体では扱えないストレージ構成に対応するために存在します。

システム起動フロー（initramfs の役割）

① BIOS / UEFI
ハードウェアの初期化・ブートデバイスの選択
↓
② ブートローダ（GRUB）
vmlinuz と initrd.img を読み込んでメモリに展開
↓
③ カーネル初期化
vmlinuz が自己展開・ハードウェア検出・基本初期化
↓
④ initramfs の展開・実行
tmpfs 上に展開 → /init スクリプトが実行 → 必要なドライバをロード → 本来のルートFSをマウント
↓
⑤ 本来のルートFS（/）へ切り替え
switch_root で本来の / に切り替え → /sbin/init（systemd）を実行

initramfs の内容を確認する

# initramfs ファイルの確認
$ ls -lh /boot/initrd.img-$(uname -r)
-rw-r--r-- 1 root root 84M /boot/initrd.img-6.8.0-51-generic

# initramfs の内容を一覧表示（lsinitramfs コマンド）
$ lsinitramfs /boot/initrd.img-$(uname -r) | head -20
.
bin
bin/sh
etc
init
lib
lib/modules/6.8.0-51-generic/kernel/fs/ext4/ext4.ko.zst
sbin
sbin/modprobe
...

# initramfs を手動で展開して内容を確認
$ mkdir /tmp/initramfs-extract
$ cd /tmp/initramfs-extract
$ zcat /boot/initrd.img-$(uname -r) | cpio -idmv 2>/dev/null | head
.
bin
etc
init
...

initramfs の生成・更新（タブで切り替え）

update-initramfs コマンド

# 現在のカーネルの initramfs を更新
$ sudo update-initramfs -u
update-initramfs: Generating /boot/initrd.img-6.8.0-51-generic

# 特定バージョンの initramfs を新規作成
$ sudo update-initramfs -c -k 6.8.0
#                       ↑-c：create（新規）  ↑-k：カーネルバージョン

# すべてのカーネルの initramfs を更新
$ sudo update-initramfs -u -k all

# 特定バージョンの initramfs を削除
$ sudo update-initramfs -d -k 6.7.0
#                       ↑-d：delete（削除）

# 詳細表示付きで更新
$ sudo update-initramfs -u -v
オプション説明
-uupdate：既存の initramfs を更新
-ccreate：新規に initramfs を作成
-ddelete：initramfs を削除
-k バージョン対象カーネルバージョンを指定（all で全バージョン）
-v詳細表示（verbose）

mkinitrd コマンド（旧来の方法）

# mkinitrd（RHEL/CentOS 6以前・旧来の方法）
$ sudo mkinitrd /boot/initrd-6.8.0.img 6.8.0
#              ↑出力ファイルパス          ↑カーネルバージョン

# 上書きする場合は --force オプションを付ける
$ sudo mkinitrd --force /boot/initrd-6.8.0.img 6.8.0

# RHEL/CentOS 7以降は dracut が標準
$ sudo dracut --force /boot/initramfs-6.8.0.img 6.8.0
⚠️ mkinitrd について
mkinitrd は RHEL/CentOS 6 以前で使われていた旧来のコマンドです。 現在の RHEL/CentOS 7 以降・Fedora では dracut が標準となっています。 LPIC-201 の試験では両方のコマンドが出題される可能性があります。

dracut コマンド

# 現在のカーネルの initramfs を再生成（上書き）
$ sudo dracut --force

# 特定バージョン向けに生成
$ sudo dracut --force /boot/initramfs-6.8.0.img 6.8.0
#                      ↑出力ファイルパス              ↑カーネルバージョン

# 詳細表示付きで生成
$ sudo dracut --force --verbose

# initramfs の内容を確認（dracut の場合）
$ sudo dracut --list-modules

# 特定モジュールを追加して生成
$ sudo dracut --add lvm --force
オプション説明
--force既存ファイルを上書き
--verbose詳細表示
--list-modules利用可能なモジュール一覧を表示
--add モジュール特定のモジュールを追加
--omit モジュール特定のモジュールを除外
--no-hostonly汎用的な initramfs を生成（他のシステムでも使用可能）
✅ initramfs の更新が必要なタイミング
・新しいカーネルをインストールしたとき
・/etc/modprobe.d/ の設定を変更したとき
・ストレージ構成（LVM・RAID・暗号化）を変更したとき
・起動に必要なドライバを追加・変更したとき
・make install は自動的に initramfs を更新するため、通常は手動実行不要

⑤ カーネル起動パラメータ（GRUB経由）

重要ポイント④：カーネル起動パラメータはGRUBのブートメニューまたは /etc/default/grub で設定し、起動時にカーネルに渡される
/proc/cmdline で現在の起動パラメータを確認できます。 
# 現在の起動パラメータを確認
$ cat /proc/cmdline
BOOT_IMAGE=/boot/vmlinuz-6.8.0-51-generic root=UUID=xxxx-xxxx ro quiet splash

# /etc/default/grub の設定例
$ cat /etc/default/grub
GRUB_DEFAULT=0
GRUB_TIMEOUT=5
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"
GRUB_CMDLINE_LINUX=""

# 起動パラメータを追加する例
# GRUB_CMDLINE_LINUX_DEFAULT に追記
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash net.ifnames=0 biosdevname=0"

# 変更後は update-grub を実行
$ sudo update-grub

主要なカーネル起動パラメータ

パラメータ説明例
root=ルートファイルシステムのデバイスroot=/dev/sda1 / root=UUID=xxxx
ro / rwルートFSを読み取り専用/読み書きでマウントro（通常は ro で起動後 rw に再マウント）
quiet起動時のカーネルメッセージを抑制quiet
splashスプラッシュスクリーンを表示splash
init=最初に実行するプロセスを指定init=/bin/bash（レスキューモード）
single / 1シングルユーザーモードで起動single
mem=使用するメモリ量を制限mem=2G
nomodesetカーネルモード設定を無効化（グラフィック問題の回避）nomodeset
net.ifnames=0ネットワークインターフェース名を eth0 形式に戻すnet.ifnames=0 biosdevname=0
