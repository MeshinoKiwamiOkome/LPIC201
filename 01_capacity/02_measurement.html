🔬 リソース使用率の測定とトラブルシューティング

CPU・メモリ・ディスク・ネットワークの使用率を各種コマンドで測定し、 ボトルネックを特定・解消する手法を学びます。

top vmstat iotop sar sadf uptime w

① 必須コマンド一覧

重要ポイント①：リソース測定コマンドは「リアルタイム系」と「履歴系」に大別される
top・vmstat・iotop はリアルタイムの状態確認に使い、 sar・sadf は過去の統計データの収集・分析に使います。
top
CPU・メモリ・プロセスをリアルタイム表示。最も基本的な監視コマンド
vmstat
仮想メモリ・CPU・I/O・スワップの統計を一覧表示
iotop
プロセスごとのディスクI/O使用量をリアルタイム表示（要root）
sar
システム全体の統計を収集・記録・表示。sysstatパッケージに含まれる
sadf
sarのデータをCSV・XML・JSONなど様々な形式で出力
uptime / w
稼働時間・ロードアベレージ・ログインユーザーを表示

② top コマンド

重要ポイント②：top はCPU・メモリ・プロセスをリアルタイムで監視する最も基本的なコマンド
デフォルトで3秒ごとに更新され、実行中に各種キー操作で表示を切り替えられます。

基本的な使い方

# 基本起動
$ top

# バッチモード（スクリプト・リダイレクト向け）
$ top -b -n 1          # 1回だけ出力して終了
$ top -b -n 3 > top.log  # 3回分をファイルに保存

# 特定ユーザーのプロセスのみ表示
$ top -u teru

# 更新間隔を5秒に変更
$ top -d 5

top の出力フォーマット（インタラクティブ解説）

top - 10:30:45 up 3 days, 2:15, 2 users, load average: 0.52, 0.48, 0.41
Tasks: 312 total, 1 running, 311 sleeping, 0 stopped, 0 zombie
%Cpu(s): 12.5 us, 3.2 sy, 0.0 ni, 83.1 id, 0.8 wa, 0.0 hi, 0.4 si, 0.0 st
MiB Mem : 7850.4 total, 1204.8 free, 4821.2 used, 1824.4 buff/cache
MiB Swap: 2048.0 total, 1980.0 free, 68.0 used, 2820.0 avail Mem
 
PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND
1234 teru 20 0 512m 128m 48m S 12.5 1.6 0:32.14 firefox
5678 root 20 0 256m 64m 32m S 3.2 0.8 1:04.28 Xorg
890 teru 20 0 128m 32m 16m S 0.0 0.4 0:01.02 bash
us（user）
ユーザープロセスが使用しているCPU時間の割合
sy（system）
カーネルが使用しているCPU時間の割合
id（idle）
CPUがアイドル状態の割合。高いほど余裕あり
wa（iowait）
I/O待ちのCPU時間の割合。高いとディスクがボトルネック
zombie
ゾンビプロセス数。0以外の場合は要調査
Swap used
スワップ使用量。増加傾向はメモリ不足のサイン

top 実行中のキー操作

キー動作
q終了
hヘルプ表示
kプロセスにシグナルを送る（PIDを入力）
rプロセスのnice値を変更（renice）
Mメモリ使用量でソート
PCPU使用率でソート（デフォルト）
T累積CPU時間でソート
1CPUコアごとの使用率を表示
u特定ユーザーのプロセスのみ表示
d更新間隔を変更
W現在の設定を ~/.toprc に保存

③ vmstat コマンド

重要ポイント③：vmstat はメモリ・スワップ・CPU・I/O・プロセスの統計を一画面で確認できる強力なコマンド
vmstat 間隔 回数 の形式で定期的に出力でき、傾向の把握に役立ちます。

基本的な使い方

# 基本（現在の状態を1回表示）
$ vmstat

# 2秒ごとに5回表示
$ vmstat 2 5

# メモリ単位をMBで表示
$ vmstat -S M

# ディスクI/O統計を表示
$ vmstat -d

# スラブキャッシュの統計を表示
$ vmstat -m

# タイムスタンプ付きで表示
$ vmstat -t 2 5

vmstat の出力フィールド解説（インタラクティブ）

procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
r b swpd free buff cache si so bi bo in cs us sy id wa st
1 0 68 1204 512 1312 0 0 120 80 450 820 12 3 84 1 0
⚠️ vmstat のトラブルシューティングポイント
・si/so が継続的に0以外 → メモリ不足（スワッピング発生）
・wa が継続的に高い（20%超） → ディスクI/Oボトルネック
・r がCPUコア数を継続的に超える → CPU不足
・cs が極端に高い → プロセス数過多またはスレッド設計の問題

④ iotop コマンド

重要ポイント④：iotop はプロセスごとのディスクI/O使用量をリアルタイムで表示する。topのI/O版
実行にはroot権限（または sudo）が必要です。 sysstat とは別パッケージで、sudo apt install iotop でインストールします。

基本的な使い方

# インストール（未インストールの場合）
$ sudo apt install iotop

# 基本起動（root権限が必要）
$ sudo iotop

# I/Oを実際に行っているプロセスのみ表示
$ sudo iotop -o

# バッチモード（1回だけ出力）
$ sudo iotop -b -n 1

# 特定プロセスのI/Oのみ表示
$ sudo iotop -p 1234

# 更新間隔を5秒に設定
$ sudo iotop -d 5

iotop の出力フォーマット

Total DISK READ: 12.50 M/s | Total DISK WRITE: 4.20 M/s
Current DISK READ: 12.50 M/s | Current DISK WRITE: 4.20 M/s
TID PRIO USER DISK READ DISK WRITE SWAPIN IO> COMMAND
1234 be/4 teru 10.50 M/s 2.10 M/s 0.00 % 85.20 % dd if=/dev/sda
5678 be/4 root 1.80 M/s 1.80 M/s 0.00 % 8.40 % rsync
890 be/4 teru 0.20 M/s 0.30 M/s 0.00 % 1.20 % firefox
フィールド意味
TIDスレッドID
PRIOI/Oスケジューリング優先度（be=ベストエフォート、rt=リアルタイム）
DISK READプロセスのディスク読み込み速度
DISK WRITEプロセスのディスク書き込み速度
SWAPINスワップイン待ちの割合
IO>I/O待ちの割合（高いほどI/Oがボトルネック）

⑤ sar / sadf コマンド

重要ポイント⑤：sar はシステム統計を定期収集・記録・表示する。過去の状態を遡って確認できる唯一のコマンド
sysstat パッケージに含まれ、cronで自動収集されたデータを /var/log/sysstat/（または /var/log/sa/）に保存します。

sar のインストールと設定

# sysstatのインストール
$ sudo apt install sysstat

# sysstatの有効化（/etc/default/sysstatを編集）
$ sudo sed -i 's/ENABLED="false"/ENABLED="true"/' /etc/default/sysstat
$ sudo systemctl restart sysstat

# データ収集ファイルの場所
$ ls /var/log/sysstat/
sa01  sa02  sa03  ...  sa31   # 日付ごとのファイル

sar の主なオプション（タブで切り替え）

# CPU使用率を2秒ごとに5回表示
$ sar -u 2 5

# 本日のCPU使用率の履歴を表示
$ sar -u

# 特定日のCPU使用率（例：3日前）
$ sar -u -f /var/log/sysstat/sa03

# コアごとのCPU使用率
$ sar -P ALL

# 出力例
10:00:01  CPU    %user  %nice %system %iowait  %steal  %idle
10:00:01  all    12.50   0.00    3.20    0.80    0.00   83.50
10:10:01  all     8.30   0.00    2.10    1.20    0.00   88.40

# メモリ使用率を表示
$ sar -r 2 5

# スワップ使用率を表示
$ sar -S 2 5

# スワップイン・アウトを表示
$ sar -W 2 5

# 出力例（-r）
10:00:01  kbmemfree kbmemused %memused kbbuffers kbcached kbcommit %commit
10:00:01    1204800   6645600    84.65    524288  1867776  8192000   52.10

# ディスクI/O統計を表示
$ sar -b 2 5

# デバイスごとのI/O統計
$ sar -d 2 5

# 出力例（-b）
10:00:01   tps   rtps   wtps   bread/s   bwrtn/s
10:00:01  45.20  30.10  15.10   2048.00    640.00
#          ↑転送/秒 ↑読み/秒 ↑書き/秒 ↑読みブロック/秒 ↑書きブロック/秒

# ネットワーク統計（DEV：インターフェースごと）
$ sar -n DEV 2 5

# ネットワークエラー統計
$ sar -n EDEV 2 5

# TCP統計
$ sar -n TCP 2 5

# 出力例（-n DEV）
10:00:01  IFACE  rxpck/s  txpck/s  rxkB/s  txkB/s  rxcmp/s  txcmp/s  rxmcst/s
10:00:01  eth0    120.50    98.20   480.20  392.80     0.00     0.00      0.00
10:00:01  lo        2.10     2.10     0.40    0.40     0.00     0.00      0.00

# ロードアベレージとプロセス数
$ sar -q 2 5

# プロセス生成数・コンテキストスイッチ
$ sar -w 2 5

# 出力例（-q）
10:00:01  runq-sz  plist-sz  ldavg-1  ldavg-5  ldavg-15  blocked
10:00:01        1       312     0.52     0.48      0.41        0

sadf コマンド（sarデータの形式変換）

# CSV形式で出力（表計算ソフトへの取り込みに便利）
$ sadf -d /var/log/sysstat/sa03 -- -u

# XML形式で出力
$ sadf -x /var/log/sysstat/sa03 -- -u

# JSON形式で出力
$ sadf -j /var/log/sysstat/sa03 -- -u

# 時間範囲を指定して出力
$ sadf -s 09:00:00 -e 12:00:00 /var/log/sysstat/sa03 -- -u
✅ sar と sadf の使い分け
・sar：ターミナルで人間が読む形式で統計を確認する
・sadf：収集済みデータをCSV/XML/JSONに変換して外部ツール（Excelやグラフツール）で分析する

⑥ uptime / w コマンド

# uptime：稼働時間・ユーザー数・ロードアベレージを表示
$ uptime
 10:30:45 up 3 days,  2:15,  2 users,  load average: 0.52, 0.48, 0.41

# 稼働時間のみ表示（-p オプション）
$ uptime -p
up 3 days, 2 hours, 15 minutes

# 起動時刻を表示（-s オプション）
$ uptime -s
2026-06-10 08:15:30

# w：ログインユーザーと実行コマンドも表示
$ w
 10:30:45 up 3 days,  2:15,  2 users,  load average: 0.52, 0.48, 0.41
USER     TTY      FROM             LOGIN@   IDLE JCPU   PCPU WHAT
teru     pts/0    192.168.1.10     10:00    0.00s  0.10s  0.02s w
root     pts/1    192.168.1.11     09:30    5:00   0.20s  0.20s bash
フィールド（w）意味
USERログインユーザー名
TTY端末名
FROM接続元ホスト/IPアドレス
LOGIN@ログイン時刻
IDLE最後の操作からの経過時間
JCPUその端末で使用した累積CPU時間
PCPU現在のプロセスが使用しているCPU時間
WHAT現在実行中のコマンド

⑦ リソース別：測定コマンド早見表（インタラクティブ）

📌 コマンドまとめ一覧

コマンド主な用途よく使うオプション特徴
top CPU・メモリ・プロセスのリアルタイム監視 -b -n -u -d 対話操作可（M/P/1/kキーなど）
vmstat メモリ・スワップ・CPU・I/Oの統計 -S M -d -m -t vmstat 間隔 回数で定期出力
iotop プロセスごとのディスクI/O -o -b -p -d root権限必要。別途インストール
sar システム統計の収集・記録・表示 -u -r -b -n DEV -q -f 過去データの確認が可能。sysstatパッケージ
sadf sarデータの形式変換 -d（CSV） -x（XML） -j（JSON） 外部ツールへのデータ連携に使用
uptime 稼働時間・ロードアベレージ -p -s シンプルで素早い確認に便利
w ログインユーザー・ロードアベレージ — uptimeの情報＋ユーザー情報を表示
