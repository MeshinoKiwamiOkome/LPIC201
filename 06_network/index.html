① ネットワークデバイス

重要ポイント①：Linux のネットワークインターフェースは ip コマンドで管理する。従来の ifconfig・route は非推奨
systemd 環境では Predictable Network Interface Names（enp3s0 など）が使用されます。

ネットワークインターフェースの命名規則

命名パターン意味例
eth0旧来の命名（カーネル検出順）eth0, eth1
enp3s0PCI バス位置ベース（en=Ethernet, p=PCI bus, s=slot）enp3s0, enp0s3
ens3PCI ホットプラグスロット番号ens3, ens33
enx001122334455MAC アドレスベースenx001122334455
wlan0旧来の無線 LANwlan0
wlp2s0PCI バス位置ベースの無線 LANwlp2s0
loループバックインターフェースlo（127.0.0.1）

ip コマンドによるインターフェース管理

# インターフェース一覧と状態を表示
$ ip link show
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
2: enp3s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP
    link/ether aa:bb:cc:dd:ee:ff brd ff:ff:ff:ff:ff:ff

# IP アドレスの表示
$ ip addr show
$ ip a                  # 短縮形
2: enp3s0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500
    inet 192.168.1.10/24 brd 192.168.1.255 scope global enp3s0
    inet6 fe80::1/64 scope link

# IP アドレスを設定
$ sudo ip addr add 192.168.1.10/24 dev enp3s0

# IP アドレスを削除
$ sudo ip addr del 192.168.1.10/24 dev enp3s0

# インターフェースを有効化・無効化
$ sudo ip link set enp3s0 up
$ sudo ip link set enp3s0 down

# MTU を変更
$ sudo ip link set enp3s0 mtu 9000

# MAC アドレスを変更
$ sudo ip link set enp3s0 address aa:bb:cc:dd:ee:ff

# 旧来の ifconfig コマンド（参考）
$ ifconfig                          # 全インターフェース表示
$ sudo ifconfig enp3s0 192.168.1.10 netmask 255.255.255.0
$ sudo ifconfig enp3s0 up

永続的なネットワーク設定

## Debian / Ubuntu 系（/etc/network/interfaces）
$ sudo vi /etc/network/interfaces
auto lo
iface lo inet loopback

auto enp3s0
iface enp3s0 inet static
    address 192.168.1.10
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4

## DHCP の場合
iface enp3s0 inet dhcp

## Netplan（Ubuntu 18.04以降の標準）
$ sudo vi /etc/netplan/01-netcfg.yaml
network:
  version: 2
  ethernets:
    enp3s0:
      addresses: [192.168.1.10/24]
      gateway4: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]
$ sudo netplan apply

## RHEL / CentOS 系（/etc/sysconfig/network-scripts/）
$ sudo vi /etc/sysconfig/network-scripts/ifcfg-enp3s0
DEVICE=enp3s0
BOOTPROTO=static
IPADDR=192.168.1.10
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
ONBOOT=yes

② ARP（Address Resolution Protocol）

重要ポイント②：ARP は IP アドレスから MAC アドレスを解決するプロトコル。arp コマンドまたは ip neigh コマンドで ARP テーブルを確認・操作する

ARP の仕組み

【ARP の動作フロー】
ホスト A（192.168.1.10）が ホスト B（192.168.1.20）に通信したい
→ ARP Request（ブロードキャスト）：「192.168.1.20 の MAC アドレスは誰？」
→ ARP Reply（ユニキャスト）：「私が 192.168.1.20 です。MAC は aa:bb:cc:dd:ee:ff」
→ ARP テーブルに 192.168.1.20 → aa:bb:cc:dd:ee:ff を記録 
# ARP テーブルを表示（ip neigh：推奨）
$ ip neigh show
192.168.1.1  dev enp3s0 lladdr aa:bb:cc:11:22:33 REACHABLE
192.168.1.20 dev enp3s0 lladdr aa:bb:cc:dd:ee:ff STALE
192.168.1.30 dev enp3s0 lladdr 11:22:33:44:55:66 DELAY
# REACHABLE=到達可能, STALE=古い, DELAY=確認中, FAILED=到達不可

# 旧来の arp コマンド
$ arp -n                    # ARP テーブルを表示（名前解決なし）
Address          HWtype  HWaddress           Flags Iface
192.168.1.1      ether   aa:bb:cc:11:22:33   C     enp3s0
192.168.1.20     ether   aa:bb:cc:dd:ee:ff   C     enp3s0

# 静的 ARP エントリを追加
$ sudo ip neigh add 192.168.1.50 lladdr aa:bb:cc:00:11:22 dev enp3s0
$ sudo arp -s 192.168.1.50 aa:bb:cc:00:11:22

# ARP エントリを削除
$ sudo ip neigh del 192.168.1.50 dev enp3s0
$ sudo arp -d 192.168.1.50

# ARP キャッシュをフラッシュ
$ sudo ip neigh flush all

# arping：ARP レベルの疎通確認
$ sudo arping -I enp3s0 192.168.1.1
ARPING 192.168.1.1 from 192.168.1.10 enp3s0
Unicast reply from 192.168.1.1 [AA:BB:CC:11:22:33]  1.234ms

④ ルーティングの設定

重要ポイント③：ip route コマンドでルーティングテーブルを管理する。デフォルトゲートウェイと静的ルートの設定方法を理解する

ルーティングの仕組み

💻 ホスト
192.168.1.10/24
→
🔀 ルーター
（デフォルト GW）
192.168.1.1
→
🌐 インターネット
（0.0.0.0/0） 
# ルーティングテーブルを表示
$ ip route show
default via 192.168.1.1 dev enp3s0 proto dhcp src 192.168.1.10 metric 100
192.168.1.0/24 dev enp3s0 proto kernel scope link src 192.168.1.10
172.16.0.0/16 via 192.168.1.254 dev enp3s0

# デフォルトゲートウェイを設定
$ sudo ip route add default via 192.168.1.1
$ sudo ip route add default via 192.168.1.1 dev enp3s0

# デフォルトゲートウェイを削除
$ sudo ip route del default

# 静的ルートを追加（172.16.0.0/16 → 192.168.1.254 経由）
$ sudo ip route add 172.16.0.0/16 via 192.168.1.254

# 静的ルートを削除
$ sudo ip route del 172.16.0.0/16

# 特定の宛先への経路を確認
$ ip route get 8.8.8.8
8.8.8.8 via 192.168.1.1 dev enp3s0 src 192.168.1.10

# 旧来の route コマンド（参考）
$ route -n                                   # ルーティングテーブル表示
$ sudo route add default gw 192.168.1.1    # デフォルトGW 設定
$ sudo route add -net 172.16.0.0/16 gw 192.168.1.254

# IP フォワーディングを有効化（ルーター設定）
$ sudo sysctl -w net.ipv4.ip_forward=1
$ echo "net.ipv4.ip_forward=1" | sudo tee -a /etc/sysctl.conf

⑤ 無線ネットワークの設定

重要ポイント④：無線 LAN の設定は iw（新）または iwconfig（旧）コマンドで行う。WPA/WPA2 の認証には wpa_supplicant を使用する

無線 LAN の管理コマンド

## iw コマンド（現代の標準）

# 無線インターフェースの一覧表示
$ iw dev
phy#0
        Interface wlp2s0
                ifindex 3
                wdev 0x1
                addr aa:bb:cc:dd:ee:ff
                type managed

# 無線インターフェースの詳細情報
$ iw dev wlp2s0 info

# 周辺の AP をスキャン
$ sudo iw dev wlp2s0 scan | grep SSID
        SSID: MyHomeNetwork
        SSID: NeighborNetwork

# 接続状態を確認
$ iw dev wlp2s0 link
Connected to aa:bb:cc:11:22:33 (on wlp2s0)
        SSID: MyHomeNetwork
        freq: 5180
        RX: 1234567 bytes (9876 packets)
        TX: 7654321 bytes (6543 packets)
        signal: -45 dBm
        tx bitrate: 300.0 MBit/s MCS 15 40MHz

## iwconfig コマンド（旧来）
$ iwconfig                          # 全無線インターフェース表示
$ iwconfig wlp2s0                   # 特定インターフェースの情報
$ sudo iwconfig wlp2s0 essid "MySSID"  # SSID を設定
$ sudo iwconfig wlp2s0 key s:password  # WEP キーを設定（非推奨）

## iwlist コマンド（旧来）
$ sudo iwlist wlp2s0 scan           # AP をスキャン
$ iwlist wlp2s0 frequency           # 利用可能な周波数を表示

WPA/WPA2 接続（wpa_supplicant）

# wpa_supplicant のインストール
$ sudo apt install wpasupplicant

# /etc/wpa_supplicant/wpa_supplicant.conf の設定
$ sudo vi /etc/wpa_supplicant/wpa_supplicant.conf
ctrl_interface=DIR=/var/run/wpa_supplicant GROUP=netdev
update_config=1
country=JP

network={
    ssid="MyHomeNetwork"
    psk="mypassword"
    key_mgmt=WPA-PSK
}

# パスフレーズをハッシュ化して設定（推奨）
$ wpa_passphrase "MyHomeNetwork" "mypassword"
network={
        ssid="MyHomeNetwork"
        #psk="mypassword"
        psk=a1b2c3d4e5f6...（ハッシュ化されたパスフレーズ）
}

# wpa_supplicant を起動
$ sudo wpa_supplicant -B -i wlp2s0 -c /etc/wpa_supplicant/wpa_supplicant.conf
# -B：バックグラウンドで実行

# DHCP で IP アドレスを取得
$ sudo dhclient wlp2s0

# NetworkManager を使用する場合（現代の標準）
$ nmcli dev wifi list                          # AP 一覧
$ nmcli dev wifi connect "MyHomeNetwork" password "mypassword"
$ nmcli connection show                        # 接続一覧
